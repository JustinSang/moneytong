## ③ writer_rules.md 구체 수정안

사용자 이탈(0초 세션)을 막기 위해, **글의 최상단(Above the Fold) 영역에 대한 강제 규칙**을 추가합니다.

| 항목 | 수정 전 (Before) | 수정 후 (After) |
| :--- | :--- | :--- |
| **2. 구조 (Retention Hook 강화)** | 상단에 행동요구 블록을 배치: 계산기 / 30초 자가진단 / 체크리스트 / 신청 플로우. | 상단에 **[즉각적 가치 확인]** 블록 배치 필수:<br>1. **결과 요약**: 클릭 없이도 보이는 '핵심 비교표' 또는 '수치 결과'.<br>2. **상호작용 유도**: 사용자가 즉시 숫자를 입력하거나 체크할 수 있는 인터랙티브 요소(Calculator 등)를 **첫 화면(스크롤 전)**에 노출하여 세션 시간 확보. |
| **3. 검색 3중 최적화 (GEO/AEO 보완)** | **GEO**: 글 최상단 3~4줄 요약 박스 → AI 검색요약에 통째로 실리게. | **GEO+Retention**: 글 최상단 3~4줄 요약 박스 + **[Quick Win]** 섹션.<br>- 사용자가 페이지 접속 후 **5초 이내**에 "내가 얻을 이득(예: 월 1만원 절감)"을 숫자로 인지하게 함. |
